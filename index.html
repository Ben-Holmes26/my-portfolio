FilletTrackOS

In development · Self-hosted

Turns photos of handwritten fish-filleting tally sheets into priced, payable records. A phone snaps the sheet, an OCR pipeline reads the rows, and the system matches workers and fish types, prices every line and tracks payment. Uncertain reads are always flagged for a person to confirm and never guessed.

  • Clean-architecture .NET solution, with multi-tenant data isolation built in from the start
  • Python OCR sidecar (PaddleOCR), with an optional local LLM through Ollama
  • Integration tests covering the full upload → review → approve → pay flow
